# 香港麻雀釣魚

**立即遊玩：** https://timmylaikh.github.io/Mahjong-fishing/?v=1.4.150

一個**純靜態**的香港麻雀釣魚小遊戲：在海底釣起麻將牌，湊成四組一將並胡牌。沒有框架、沒有打包步驟；所有規則判定都由 `js/rules.js` 這個純模組負責，因此 `node tests/rules.test.mjs` 可以直接在 Node 執行。

## 執行

因為使用 ES modules，必須透過 HTTP 伺服器開啟（直接點 `index.html` 的 `file://` 網址會被瀏覽器擋住）：

```bash
cd Mahjong-fishing
python3 -m http.server 8000
# 開啟 http://localhost:8000/index.html
```

執行規則、賠率、連線與介面靜態測試：

```bash
node tests/rules.test.mjs
node tests/payout.test.mjs
node tests/net.test.mjs
node tests/hkma-ui.test.mjs
# 或：npm test（目前只執行規則測試，仍需另外執行上述三項）
```

> Node 不在全域 PATH 時，可使用 `/home/timmy/.local/node/bin/node`。

重新下載／重新產生圖片素材（需要 `curl`、`file`、`python3` 與 Pillow）：

```bash
bash scripts/fetch_assets.sh
python3 scripts/process_assets.py
```

`scripts/process_assets.py` 會呼叫 `scripts/restyle_tiles.py`，只把核准的綠／灰平滑邊層烘焙進最終 PNG（120×181 RGBA，不再有柔陰影或面色重調）；也可單獨執行 `python3 scripts/restyle_tiles.py 輸入資料夾 輸出資料夾` 重新套用風格。

## 玩法

1. 一般座位起始 13 張手牌，莊家 14 張。點擊畫面或按空白鍵拋竿；鉤子**出去與收回時**只要碰到魚就會鉤起牌。約每七張魚有一張會在出現 **3 秒**後翻到背面，**3 秒**後再翻回正面考驗記憶；一旦鉤起就會翻開。
2. 開局由無限加權牌池隨機派 13 張普通牌；花牌（春、夏、秋、冬、梅、蘭、菊、竹）另外亮在「花牌」區，不進手牌，也沒有「花牌 0/8」的空面板。遊戲中釣到花牌只亮出，不自動補牌，由玩家自己鉤下一張。集齊七張即「花糊」（3 番，已含自摸）、八張即「大花糊」（10 番），可即時胡牌；七花可選「過」拒絕，拒絕後只接受八花即時胡，日後以手牌胡牌時才加計花糊番。開局只有莊家拿 14 張，起手已成牌即 **天胡**（10 番，已含自摸與門前清）；其他三家一律 13 張起步，直接拋竿，沒有暗補第十四張。閒家鉤起第一張非花牌即時成胡為 **人胡**（10 番，已含自摸與門前清），先釣到花牌不會浪費這次機會；閒家胡莊家開局第一隻打出牌則為 **地胡**（10 番），該張之後不再計。**一開牌已有七張花以上，或在第一次補花時摸齊七花：莊家另計天胡、閒家另計地胡；暗槓或其他槓後補到七花則只計槓上開花，不計天地胡。**番數以香港麻雀協會《香港麻雀總例》為準；人胡、七對子、綠一色與藍一色為本遊戲保留的自訂牌型。
3. 手上有四張相同的牌時，竿子左側會出現「開槓／不開槓」內嵌提示（不彈出全螢幕視窗）；開槓後不自動補牌，玩家自己鉤起的下一張才算補牌，胡牌為「槓上開花」。連續開槓計「連槓開花」，但**槓與槓之間不可補花**：補到花即斷開連槓，下一張視作普通鉤牌，不再計槓上開花／連槓開花。槓上開花與連槓開花也不再另計海底撈月。明槓後補牌成胡時採用**出槓**：由當初打出被槓牌子的人支付，如同放槍；連槓則以第一槓的性質判定，第一槓是暗槓／加槓仍按自摸三家支付。
4. 另外三位對手**允行、一心、念慈**是完整玩家：各有私人手牌、花牌、副露、河與透明幽靈釣竿，從同一片海裡自己釣牌、自己決定打哪張，也能自摸或胡你的出牌。任何人打出的牌會展示 **5 秒**；釣竿右側會顯示該牌的圖片、出牌者與門風，以及胡／碰／上／明槓按鈕；桿子不會停止擺動，玩家可照常拋竿、鉤牌與打牌，HUD 不再顯示對手出牌資訊。`胡牌`、`碰`（兩張相同）、`明槓`（三張相同）可向任一對手宣告；`上`（兩張鄰牌組成順子，有多種組合會逐一列出）只能向你的**上家**（前一個門風）宣告。逾時自動放棄，不會另外彈出通知視窗；碰／上後都要先打出一張牌，才能再對其他牌宣告；明槓則再釣一張牌補槓，不會要求立即打牌。自己釣牌成胡時，釣竿左側會出現「胡牌／過」提示（同時可開槓時亦會列出開槓）；選「胡牌」才會開啟結算視窗，選「過」則打出一張牌繼續。不論自摸或胡別人的牌，按下「胡牌」即時結束本局並同步給所有裝置，不會只停用按鈕等待房主判定。**唯一例外是十三么牌王**：聽十三么的玩家在該牌五秒視窗內享有絕對優先，其他人的胡／槓／碰／上都會被鎖住，直到牌王胡牌、按「過」或視窗結束；多位牌王同時聽牌時先按先贏。除此之外所有胡／槓／碰／上都是先按先贏。開明槓時任何聽該牌的胡牌都可以「搶槓」（加 1 番），開暗槓時只有十三么能搶；被搶者視作出銃，槓與補牌全部取消。碰、上、槓才會失去門前清，吃胡他人打出的牌仍可計門前清，但不計自摸。九子連環可在門前清聽牌時吃胡他人打出牌，不必自摸；坎坎胡吃胡他人打出牌時必須湊成單騎，吃胡刻子降為對對糊，仍可計門前清。畫面不另外顯示河。
5. 打牌階段滑鼠移過手牌即選中，點一下手牌即打出，或用 ←/→ 選擇、Enter 打出；手機／平板改成點第一下先選取並預覽聽牌，再點同一張選中的牌才打出。能打出後聽牌的牌會上下跳動提示。
6. 每局時間在開始前的房間設定拖曳滑桿或直接輸入「分:秒」（00:30–30:00），畫面上方以大字顯示；時間到即流局。鉤子會隨巡數與時間逐步加快；「重來這局」會保留目前巡數，只重置牌局與時間。HUD 右側顯示「X風第 X 局・X 圈」，其下才是門風與資金（金額前加 `$`），不再顯示巡數、番數與最佳；「各家副露」固定顯示在自己的花牌與暗槓上方，每位對手依序顯示圖示、名稱、目前資金（前有 `$`）與目前門風。遊戲畫布從固定高度的 HUD 下方開始，HUD 已預留足夠空間一次顯示各家副露、花牌與手牌，不需要捲動，剩餘空間會平均分配而不會堆在底部，「打出 → 暫無聽牌」提示列也保留完整牌圖高度，不會改變魚海範圍；靜止鉤子貼近 HUD 下緣；竿子可擺動近 170 度，鉤子垂直放下時直達海底，擺到最側時則可觸及魚海上方兩側邊緣。魚的位置以海寬比例、游速以固定參考寬度記錄；房主切換分頁時魚海暫停，回到遊戲時依離開時間補齊，縮小化、調整視窗大小或手機轉向都不會讓魚群跳位或變速。開啟「設定」、「玩法說明」、「重來這局」投票或「計分」時魚海、計時、鉤子與 AI 都會繼續，單機與聯機都一樣。宣告框在鉤子外出時仍會顯示，只把按鈕禁用。海面就在鉤子下方，上方有遠山、草地岸地、小屋與竹子，幾乎整個遊樂區都是水域。
7. 魚海是無限加權牌池：34 種普通牌每種權重 4，8 張花牌每種權重 1；魚的牌種完全隨機，不配合任何人手牌，也沒有牌數上限，同一種牌可以超過四張。每局時間（00:30–30:00，可拖曳滑桿或輸入「分:秒」）與鉤速（同時調整竿子擺動、出鉤與收鉤的基礎速度，0.5×–2.0×）請在開始前的房間設定；「設定」只保留玩家名稱、兩個開關（背景音樂、音效與語音）、主音量（0%–100%）與音樂音量（0%–100%，0% 即靜音）與「重來這局」；背景音樂開關只控制音樂，音效與語音開關控制語音、點擊與牌聲；主音量會乘以音樂音量；上限番數由房主在開局前設定，可選 10 番或無限（預設 10 番）。聽牌提示永遠開啟。只有累計番數存放在 `localStorage`；最佳番數變數、`mf-bestfan` 與所有最佳紀錄顯示都已移除。「玩法說明」分為玩法說明、牌型一覽、派彩計算表三個分頁，沒有「前往番數表」跳轉按鈕；四種自訂牌型排在牌型一覽最底。派彩計算表另有 0–10 番金錢派彩計算表與規則來源註腳。每場資金與派彩紀錄請見下節。
8. HUD 左側與聯機房間等待畫面都有「表情」按鈕，可挑選一個 emoji 送出；該座位頭像旁會浮出表情與名字，聯機時房主會轉送給其他玩家，開局前與牌局中所有人都能看到。表情只是聊天提示，不影響牌局或計分。自己打出牌時有短促碰撞音；開局、胡牌、流局與宣告上／碰／槓都會用裝置本身的香港粵語語音讀出。只會選用明確標示 `zh-HK`／粵語的語音，沒有就略過，不會改讀普通話；語音跟隨「音效與語音」開關與主音量；iPhone Safari 的語音合成仍受靜音開關影響，需關閉靜音模式才聽得到（改用 Chrome 亦可）；iPhone 亦不允許網頁更改 `<audio>` 音量，所以音樂音量滑桿在 iPhone 上無效，需使用手機音量鍵。語音會逐句排隊，不在新語音前取消正在播放的語句，避免干擾正在播放的語音；先前開局語音後出現的凍結，實際上是 AI 強制出牌時的程式錯誤造成，已修正，語音本身不會暫停遊戲；手機若沒有明確的香港／粵語語音便會保持靜默，不會改讀普通話，也不影響牌局。牌面的兩層平滑邊已烘焙進 43 張 120×181 RGBA PNG（由 `scripts/restyle_tiles.py` 產生），不再有柔陰影或面色重調，也不再用 CSS 或 canvas 疊加斜角。HUD 局數旁會顯示本場起糊番數；AI 出銃、胡牌、上／碰／明槓、流局與比賽結束時有機會以既有 emoji 回應，不影響牌局或計分。

## 計分與資金

- 單機在開始前的「單機房間」、聯機由房主在「聯機房間」於開局前設定：每人起始資金（1–100,000,000，預設 20，可拖曳或輸入精確數字）、圈子數（1–4，預設 1 圈）、金額倍數（1×–100×，預設 1×）、起糊（0–10 番，預設 3 番；達到指定番數才算胡牌）與上限番數（10 番／無限，預設 10 番）。鉤速（預設 1.0×）與每局時間（預設 05:00）也同在房間設定；「設定」不再調整鉤速、時間與場次資金。一局開始後設定即鎖定；整場結束後房主可在開新一場前回到房間重新選擇以上設定。
- 賠率表以金額倍數為單位：V(0)=1、V(1)=2、V(2)=4、V(3)=8、V(4)=16，之後每兩番加倍、單數番先乘 1.5，例如 V(5)=24、V(7)=48、V(9)=96、V(13)=384、V(25)=24576。公式：番 ≤ 4 時 `V = 2^番 × 金額倍數`；番 ≥ 5 時 `V = 16 × 2^⌊(番−4)/2⌋ × (番−4 為奇數 ? 1.5 : 1) × 金額倍數`。玩法說明另有 0–10 番完整倍率與支付表。
- 出銃時由出銃者支付 V 給胡牌者；自摸時其餘三家各付 V／2（四捨五入），胡牌者共得 1.5 × V，且自摸至少計 1 番。流局不派彩。
- 每局結算後 HUD 的資金（前有 `$`）會更新，點「計分」可查看四家排名、當前圈風、本場起糊番數與每局派彩紀錄。莊家胡牌即連莊：莊家不變、圈數不推進；非莊家胡牌或流局則換莊並推進一手。
- 任何人資金降至 0（或以下）或打完指定圈數時整場結束，資金最多者勝。結算畫面最上方顯示剛結束那一局的「X風第 X 局・X 圈」，遊戲畫面右上角的同一行則保留到按下下一局按鈕、真正開新局才更新，接著是「圖示 名稱 胡牌!」、牌型細項、緊接在牌型下方的獲勝手牌圖片（胡別人牌時該張牌也固定在最右邊）、共 N 番、出銃或自摸金額與連莊訊息；同時以裝置的香港粵語語音讀出贏家名稱、牌型與「共 XX 番」（例如「幼羚，坎坎胡，共十番」），沒有合適語音時略過；整場勝利者會以大字顯示，底下附上按資金排序的計分板。單機按「進入下一局」立即開始新局，聯機則等所有真人按下「準備下一局」後同步開始；若整場已結束，按鈕改為「開新一場」（聯機同樣需要投票）；聯機房主也可在投票時按「房間設定」回到房間重新選擇設定，所有真人投完「開新一場」後也會回到房間，由房主按「開始遊戲」開始新的一場，兩邊都可以按「回到主選單」離開。

## 聯機遊戲（四人 P2P）

- 主選單選「單機遊戲」會先進入單機房間：三位 AI 對手自動補位，畫面沒有房間代碼與分享連結，調整設定後按「開始遊戲」才開局。選「聯機遊戲: 開新房間」會產生四位房間代碼與分享連結，選「聯機遊戲: 加入房間」後才會要求輸入房間代碼。好友也可直接開啟 `?room=XXXX` 連結自動加入。新房間一開始只有房主，房主可在座位表按「加入 AI／移除 AI」自行決定要補幾位 AI；好友加入時先填補真正的空位，沒有空位才會頂掉一個 AI 座位；若四位都已是真人則拒絕加入並顯示「房間已滿，請換一個房間。」。客人要收到房主回應才會進入房間畫面，不會先看到沒有房主的空房間；若房間代碼還在配對服務上但房主已離開，等待約八秒仍收不到房主回應時會顯示「房間已關閉，請重新開房間。」，並在本次瀏覽器工作階段內記住該代碼，再次輸入會立刻拒絕，不會把客人留在無法開始的房間裡。開局時剩餘空位仍會自動補 AI，AI 名稱會附上 `(AI)`。
- 玩家名稱預設為「幼羚」（房主與單機）；加入房間的好友依座位預設為「允行／一心／念慈」。在主選單、房間大廳或遊戲設定的「玩家名稱」欄位都可修改，聯機時會同步給其他玩家。主選單展示的牌圖是合法的十三么胡牌（十三種么九與字牌各一張，再加一張作將）。
- 連線使用 PeerJS（由 CDN 載入，CDN 失敗時自動改用隨網站提供的本機副本）點對點傳訊；不需要帳號或自建伺服器，但需要網路可連到 PeerJS 公開訊號服務。有人關閉分頁時會立刻送出離開通知，房主馬上補 AI，客人也馬上看到「房主已離開」，不必等連線逾時。
- 所有人加入後都會留在等待室，倒數不會開始；由房主在大廳依序設定「鉤速」、「每局時間」（可拖曳滑桿或直接輸入「分:秒」）、「圈子數」、「起始資金」、「金額倍數」、「起糊」與「上限番數」後按「開始遊戲」，開始後所有人共用同一組設定，任何人不能再更改；客人會看到與房主相同的房間畫面，但設定欄與「開始遊戲」都是停用狀態，並標示 `(由房主設定)`。分享連結會自動帶入房間代碼。
- 四家共用同一片魚海：房主擁有魚的移動與快照，魚的位置以海寬比例、游速以固定參考寬度廣播，客人端再換算成自己畫面的座標，並在兩次快照之間依速度平滑推估，因此手機房主與 PC 客人的魚速一致、不同視窗大小都能看到魚以相同節奏持續游動，不會跳動。房主切換分頁時魚海暫停，回到遊戲時依實際離開時間一次補齊並立刻廣播，客人端不會看到魚群往回跳或大跳位；任何人開啟「設定」、「玩法說明」、「重來這局」投票或「計分」都不會暫停魚海，也不會在關閉面板後補償跳位。竿子旁邊會顯示四個依座位排列、各不相同的全身玩家圖示（幼羚、允行、一心與念慈；一心與念慈為女性），聯機等待室也有同一組圖示；幽靈鉤子旁邊會標示所屬玩家名字。按「重來這局」重新發牌時不會把舊暫停時間補到新魚上。誰先提出鉤中要求就由房主裁定誰得到那條魚，並把結果廣播給全部裝置。每台裝置只持有自己的私人手牌；起手牌各自從同一個無限加權牌池產生，房主不發牌、也不讀取他人手牌。AI 座位由房主（單機時由本機）完整模擬：自己拋竿、補花、開槓、選牌、碰上槓與胡牌；AI 的鉤子會在下降與收線途中判定鉤中，並到達海底才收竿。任何座位的竿子（含客人）都會先送到房主再轉送給其他三家，所有人都能看到半透明幽靈竿；竿子姿勢每秒廣播 20 次，接收端以前後兩幀的速度平滑推估並在收到新位置時逐步校正，因此幽靈鉤子跟得更緊，也不會在轉向時跳位。
- 不論單機或聯機，竿旁每位對手各有一個出牌欄，各自五秒倒數，到期時間由房主時鐘同步到各裝置；`胡`／`碰`／`明槓` 可向任一對手宣告，`上` 只能在你的上家欄位出現。出牌欄另有「過」按鈕，按下只忽略該張牌的這一個欄位，不影響其他出牌欄、AI 宣告或五秒逾時；碰／上成功後必須先打出一張牌，才能再對其他牌宣告；明槓則回到拋竿，再釣一張牌補槓。出牌欄在鉤子外出時不會消失，宣告按鈕會禁用，但「過」可隨時按下；鉤子空手回來，或鉤到牌並打出後，宣告按鈕才會重新啟動。按鈕與可宣告狀態會隨手牌即時重算：鉤到牌並打出後，原本不能動作的舊出牌可能出現「胡牌」；失效的上／碰／明槓不會保留。若該張牌可以胡，右側出牌欄會放大成與自己摸牌相同的綠色提示（「可以胡牌！」加牌圖與大按鈕）。手牌最多四組面子加一對將。
- 聯機計時由房主以系統時間為準，定時同步剩餘秒數給所有人；房主切到其他分頁也不會停止倒數，客人即使短時間收不到訊息也會依最後一次同步繼續計時。單機開啟設定、玩法說明、重來這局投票或計分時也照常倒數。HUD 中固定展開、位於自己花牌與暗槓上方的「各家副露」只列出其他三家的碰、上、明槓與暗槓，以及各自已亮出的花牌與花數（自己的部分已顯示在 HUD），每位對手並依序標示圖示、名稱、目前資金（前有 `$`）與目前門風，不能再收合。任一玩家（包括 AI）胡牌或時間到流局時，四台裝置會一起顯示相同的結算畫面（開頭為「X風第 X 局・X 圈」，附按資金排序的計分板），資金與連莊狀態由房主同步到各裝置；有人破產或打完指定圈數即整場結束並顯示資金最多者。所有真人玩家按下「準備下一局」後才會由房主同步開始新一局（整場結束時改為「開新一場」投票，之後全體回到房間讓房主重新設定並開新場），AI 會自動同意，也可選擇「回到主選單」。牌局中任何人按「重來這局」則會開啟重新開始投票，所有真人同意後才會重開；任何人取消即終止投票。投票訊息會顯示發起人的名字（自己才顯示「你」），名單中自己的座位會標註「（你）」。
- 有玩家離開時，其他裝置會收到短暫通知；主動離開的人不會看到「房主已離開」。房主離開時則會顯示「房主已離開，請重新開房間」，不會自動把房主轉給別人。

## 無限魚池與 AI 對手（僅供查閱，遊戲內不顯示）

魚海由 `js/rules.js` 的 `randomTileKind()` 產生，並由 `tests/rules.test.mjs` 驗證加權與無四張上限的行為。34 種普通牌每種權重 4，8 種花牌每種權重 1；每次都是獨立抽樣，沒有牌牆、沒有剩餘張數、也沒有四張限制。起手 13 張普通牌與每條新魚都來自同一個加權池，因此同一種牌可能同時出現在聯機手上或超過四張；七對子也可以由四張相同牌提供兩對。

AI 對手不是發牌 Helper，而是和其他座位一樣的玩家：

- 每個人各自從加權池拿到私人起手牌與花牌，AI 只用自己的 `rules.js` 評估自己的手，不讀取隊友或玩家的手牌。
- AI 有自己的竿子與掛鉤，會和真人一起在同一片海裡搶魚；竿子同樣在畫面可及的範圍內左右擺動，每次出鉤前會先掃到選定的角度（包含兩側底角），鉤子到達海底才開始判定鉤中，因此也能看到它伸到畫面邊緣。其他人看到的是半透明幽靈竿。房主先收到的鉤中要求先勝出。
- 鉤到花牌就亮出並檢查花糊；鉤到普通牌就加進自己的手，檢查自摸／開槓，然後花一點時間選一張對自己聽牌最有利的牌打出。
- AI 也會對別人打出的牌做胡／碰／上／明槓判定，但會稍等一小段時間，讓附近真人仍有先按的機會；碰／上後必須先打出一張牌，明槓則再釣一張牌補槓。

## 規則設計（請見 CHANGELOG 的待確認事項）

- 無限加權牌池：34 種普通牌每種權重 4，8 種花牌每種權重 1；每次抽樣彼此獨立，沒有牌牆與四張上限，游出水面的魚直接消失，同一種牌可以超過四張。規則引擎放寬 `decompose()` 與 `isSevenPairs()`，讓五張以上同牌及四張同牌當兩對仍然合法。
- 花牌不進手牌、不參與聽牌與牌型分解；開局抽到即亮出，13 張普通牌也同時從牌池湊齊，遊戲中釣到則只亮出，由玩家自己鉤下一張。番數按[香港麻雀番牌列表](https://zh.wikipedia.org/wiki/%E9%A6%99%E6%B8%AF%E9%BA%BB%E9%9B%80%E8%83%A1%E7%89%8C%E5%88%97%E8%A1%A8)計：無花 1、正花每張 1、一檯花 2（同系列正花不再計）、花糊（七花）3（已含自摸）、大花糊（八花）10。
- 風位對應：東＝春／梅，南＝夏／蘭，西＝秋／菊，北＝冬／竹。
- 本遊戲每一次**釣到**的牌都視為**自摸**；`context.selfDraw` 預設為 `true`。胡對手打出牌時傳入 `selfDraw: false`，不計自摸，但只要完全沒有碰、上、槓（包括暗槓）仍計門前清；門前清只要求沒有副露，不再要求自摸。
- 允行、一心、念慈三位對手是完整玩家：各自從同一加權池拿到私人手牌，自己釣魚、打牌、碰上槓與胡牌，完全不參考玩家手牌。任何人打出的牌展示 5 秒；牌圖、出牌者與門風及宣告按鈕都顯示在釣竿右側，不佔用 HUD。胡／碰／明槓可向任一對手宣告；上只允許向門風順序中玩家前一位的上家宣告。魚牌記憶翻轉不影響計番。
- 碰、上、明槓為**開牌**（`open: true`），暗槓（`open: false`）視作暗刻；兩者都是副露，任何一種都會讓「門前清」與「坎坎胡」不再計。吃胡他人打出的牌時，完全沒有副露仍計門前清；自摸仍只按 `context.selfDraw` 計算。
- **天胡／人胡／地胡**：天胡是莊家 14 張起手牌即成胡；人胡是閒家第一張非花牌的鉤中牌即自摸；地胡是閒家食莊家開局第一隻打出牌。三者皆 10 番，已含自摸與門前清（共用的自摸只計一次），四家（含 AI）都適用。非莊家不再有暗補第十四張的開局檢查，第一張花牌只亮出，不消耗人胡機會。
- 槓子與碰在各牌型中視為刻子，上視為順子；因此暗槓、碰仍可計入清一色、混一色與對對糊；沒有碰、上、槓（包括暗槓）才計坎坎胡。
- 「對對糊」是只有刻子的牌型（3 番）；「坎坎胡」是完全沒有碰、槓的對對胡（又稱四暗刻，10 番），已吸收對對糊與門前清。「花么九」（香港麻雀總例稱「花么」，4 番）與坎坎胡可疊加，但共用的對對糊只計一次，胡牌細項會列出「重疊扣減」。
- 自訂牌型：七對子（3 番，七種不同牌各一對）、人胡（10 番）、綠一色（10 番，只有二、三、四、六、八索或發財）、藍一色（10 番，只有東、南、西、北、白板或八筒）。這四種在「玩法說明」的牌型一覽標示為「自訂牌型」；結算與語音不另加標籤。
- 番子刻子會在胡牌細項標明中、發、白或場風／門風；場風與門風重疊時該刻子計 2 番。番子已從「小番」清單移除，所以只有番子的小牌不會再被標成雞糊。
- 疊加改採 `ABSORBS` 表：若牌型 A 依定義必定包含 B，就只計較高番的 A，並以 `includes` 顯示「已包含」；只是有時重疊的牌型（例如坎坎胡＋大三元、清么九＋坎坎胡）仍可疊加，若共用同一子牌型則以「重疊扣減」扣回重複番數。七對子、人胡、綠一色、藍一色仍保留，並在牌型一覽標示為「自訂牌型」。
- 番數上限由房主設定：10 番或無限（引擎的 `FAN_CAP` 仍為 `Infinity`，房間設定以可序列化的 `fanCapTen` 布林值同步）；房主另可設起糊（0–10 番，預設 3 番）作為胡牌最低番數。胡牌累加番數，選 10 番時結算以 10 番為上限，並依金額倍數換算場次資金（見「計分與資金」）。
- 十三么、九子連環、七對子必須保持暗手（沒有碰、上、槓，包括暗槓）；吃胡他人打出的牌時，門前清已被這些牌型吸收，不會另外列出，自訂牌型仍需合法牌型。
- 原先將七對子稱為「花糊」是誤名，現已統一改為「七對子（嚦咕嚦咕）」；「花糊」專指七張花牌。
- **海底撈月**改為：倒數**剩餘 5 秒內**自摸或胡對手打出牌並胡牌即計 1 番；自摸仍按胡牌來源另計，不因海底撈月被吸收。5 秒前胡牌則不算（由 `winContext().haidi` 判斷）。此屋規與花糊等一律納入計番。
- 背景音樂為五段 CC0 中國風器樂（Freesound，詳見 `CREDITS.md`），可隨時關閉。
