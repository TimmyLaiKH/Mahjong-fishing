# 香港麻雀釣魚

**立即遊玩：** https://timmylaikh.github.io/Mahjong-fishing/

一個**純靜態**的香港麻雀釣魚小遊戲：在海底釣起麻將牌，湊成四組一將並胡牌。沒有框架、沒有打包步驟；所有規則判定都由 `js/rules.js` 這個純模組負責，因此 `node tests/rules.test.mjs` 可以直接在 Node 執行。

## 執行

因為使用 ES modules，必須透過 HTTP 伺服器開啟（直接點 `index.html` 的 `file://` 網址會被瀏覽器擋住）：

```bash
cd Mahjong-fishing
python3 -m http.server 8000
# 開啟 http://localhost:8000/index.html
```

執行規則測試：

```bash
node tests/rules.test.mjs
# 或：npm test
```

> Node 不在全域 PATH 時，可使用 `/home/timmy/.local/node/bin/node tests/rules.test.mjs`。

重新下載／重新產生圖片素材（需要 `curl`、`file`、`python3` 與 Pillow）：

```bash
bash scripts/fetch_assets.sh
```

## 玩法

1. 起始 13 張手牌。點擊畫面或按空白鍵拋竿；鉤子**出去與收回時**只要碰到魚就會鉤起牌。約每七張魚有一張會在出現 **3 秒**後翻到背面，**3 秒**後再翻回正面考驗記憶；一旦鉤起就會翻開。
2. 開局派到花牌（春、夏、秋、冬、梅、蘭、菊、竹）會先亮在「花牌」區再補足 13 張；還沒有花牌時不會顯示「花牌 0/8」。遊戲中釣到花牌只亮出，不自動補牌，由玩家自己鉤下一張。集齊七張即「花糊」（3 番，已含自摸）、八張即「大花糊」（8 番），可即時胡牌；七花可選「過」拒絕，拒絕後只接受八花即時胡，日後以手牌胡牌時才加計花糊番。開局補花後的第一張自摸若已成牌，莊家為 **天胡**、其他門風為 **地胡**（皆 13 番，已含自摸與門前清）；若未胡牌，牌牆保持原狀，照常拋竿。
3. 手上有四張相同的牌時可以開暗槓；開槓後不自動補牌，玩家自己鉤起的下一張才算補牌，胡牌為「槓上開花」。
4. 另外三位對手**允行、一心、念慈**會從開局起不停地按門風順序輪流從牌牆**隨機**打出一張牌（不參考玩家手牌），每張牌展示 **5 秒**並自動換下一位。釣竿右側會顯示該牌的圖片、出牌者與門風，以及胡／碰／上／明槓／過按鈕；桿子不會停止擺動，玩家可照常拋竿、鉤牌與打牌，HUD 不再顯示對手出牌資訊。`胡牌`、`碰`（兩張相同）、`明槓`（三張相同）可向任一對手宣告；`上`（兩張鄰牌組成順子，有多種組合會逐一列出）只能向你的**上家**（前一個門風）宣告。也可選「過」放棄（牌仍會展示至 5 秒期滿），逾時自動換牌，不會另外彈出通知視窗。碰／上後要再打出一張牌，明槓後則直接再釣一張補牌。自己釣牌成胡時，釣竿左側會出現「胡牌／過」提示（同時可開槓時亦會列出開槓）；選「胡牌」才會開啟結算視窗，選「過」則打出一張牌繼續。畫面不另外顯示河。
5. 打牌階段滑鼠移過手牌即選中，可點手牌，或用 ←/→ 選擇、Enter 打出；能打出後聽牌的牌會上下跳動提示。
6. 每局時間可在設定中拖曳滑桿或直接輸入「分:秒」（00:30–30:00），畫面上方以大字顯示；時間到即流局。鉤子會隨巡數與時間逐步加快；「重來這局」會保留目前巡數，只重置牌局與時間。遊戲畫布從 HUD 下方開始，靜止鉤子貼近 HUD 下緣。海面就在鉤子下方，上方有遠山、草地岸地、小屋與竹子，幾乎整個遊樂區都是水域。
7. AI 輔助發牌固定永遠開啟：新出現的魚約七成會配合你手上的牌；詳細規則見下方「AI 輔助發牌規則」。設定可以調整每局時間（00:30–30:00，可拖曳滑桿或輸入「分:秒」，調整後立即重新計時）、鉤速（同時調整竿子擺動、出鉤與收鉤的基礎速度，0.5×–2.0×）、背景音樂開關與音樂音量（0%–100%，0% 即靜音）；番數上限固定為無上限。聽牌提示永遠開啟。只顯示番數，不換算分數；累計番數與「最佳番數」（單局胡牌的最高番數）存放在 `localStorage`。「牌型一覽」已放在「玩法說明」內。

## 多人遊戲（四人 P2P）

- 主選單選「單機遊戲」維持原本玩法；選「多人遊戲: 開新房間」會產生四位房間代碼與分享連結，選「多人遊戲: 加入房間」後才會要求輸入房間代碼。好友也可直接開啟 `?room=XXXX` 連結自動加入。未坐滿的位置由 AI 補位，AI 名稱會附上 `(AI)`。
- 玩家名稱預設為「幼羚」（房主與單機）；加入房間的好友依座位預設為「允行／一心／念慈」。在主選單、房間大廳或遊戲設定的「玩家名稱」欄位都可修改，多人時會同步給其他玩家。
- 連線使用 PeerJS（由 CDN 載入，CDN 失敗時自動改用隨網站提供的本機副本）點對點傳訊；不需要帳號或自建伺服器，但需要網路可連到 PeerJS 公開訊號服務。
- 所有人加入後都會留在等待室，倒數不會開始；由房主在大廳設定「鉤速」與「每局時間」後按「開始遊戲」，開始後所有人共用同一組設定，任何人不能再更改。分享連結會自動帶入房間代碼。
- 每台裝置各自執行自己的牌牆、魚群與手牌，所以同一種牌可能在不同人手上同時出現；碰／上／明槓取得的牌會讓自己擁有超過四張同牌。房主只負責轉送訊息與判定「先按先贏」，不發牌也不驗證規則；胡牌由各自用本地規則引擎判定後廣播。
- 多人時竿旁每位對手各有一個出牌欄，各自五秒倒數；`胡`／`碰`／`明槓` 可向任一對手宣告，`上` 只能在你的上家欄位出現。出牌欄沒有「過」按鈕，逾時自動放棄；碰／上／明槓成功後必須先打出一張牌，才能再對其他牌宣告。
- HUD 下方可折疊的「各家副露」只列出其餘三家的碰、上、明槓與暗槓，不顯示自己的副露。任一玩家胡牌或時間到流局時，四台裝置會一起顯示「遊戲結束」與相同結果；所有真人玩家按下「再來一局」後才會由房主同步開始新一局，也可選擇「回到主選單」。
- 房主離開時會顯示「房主已離開，請重新開房間」，不會自動把房主轉給別人。

## AI 輔助發牌規則（僅供查閱，遊戲內不顯示）

規則由 `js/rules.js` 的 `getAssistTiles()` 實作，並由 `tests/rules.test.mjs` 驗證。AI 固定永遠開啟，沒有強度或開關設定。

每次有新魚產生時：

- 約 **70%** 使用輔助候選；其餘 **30%** 直接從牌牆隨機取一張。
- 候選依 `wins` → `flowers` → `kongs` → `progress` 順序嘗試。該組有牌且擲骰命中才採用，否則繼續下一組；全部未命中時退回隨機牌。
- 各組命中率：`wins` 85%、`flowers` 75%、`kongs` 60%、`progress` 70%。
- 所有候選都受「牌牆尚餘張數」限制，不會憑空產生第五張同牌，也不會把已拿在手上的花牌再送一次。
- `wins` 呼叫完整胡牌判定，所以任何能立即胡牌的牌型都已覆蓋，包括十三幺、七對子、綠一色、藍一色、九子連環與所有普通牌型。
- `progress` 使用輕量牌數統計：已持有的牌（補對子／刻子）、同花色相差 1–2 的鄰牌，以及達到門檻的幺九／字牌（7 張）、綠／藍色牌（6 張）、字牌（6 張）、幺九牌（5 張）、單一花色（6 張）。

## 規則設計（請見 CHANGELOG 的待確認事項）

- 144 張牌牆：34 種普通牌各 4 張，加上 8 張不重複的花牌。游出水面的魚會把牌放回牌牆，整局任何普通牌都不會超過 4 張。
- 花牌不進手牌、不參與聽牌與牌型分解；開局摸到即亮出並補足手牌，遊戲中釣到則只亮出，由玩家自己鉤下一張。番數按[香港麻雀番牌列表](https://zh.wikipedia.org/wiki/%E9%A6%99%E6%B8%AF%E9%BA%BB%E9%9B%80%E8%83%A1%E7%89%8C%E5%88%97%E8%A1%A8)計：無花 1、正花每張 1、一檯花 2（同系列正花不再計）、花糊（七花）3（已含自摸）、大花糊（八花）8。
- 風位對應：東＝春／梅，南＝夏／蘭，西＝秋／菊，北＝冬／竹。
- 本遊戲每一次**釣到**的牌都視為**自摸**；`context.selfDraw` 預設為 `true`。胡對手打出牌時傳入 `selfDraw: false`，不計自摸；此番只取決於該旗標，不再受副露影響。
- 允行、一心、念慈三位對手從開局起依門風順序輪流從牌牆隨機打出一張牌，不套用魚群的 AI 輔助、也不參考玩家手牌。每張牌展示 5 秒後自動換下一位，與玩家是否拋竿或打牌無關；牌圖、出牌者與門風及宣告按鈕都顯示在釣竿右側，不佔用 HUD。胡／碰／明槓可向任一對手宣告；上只允許向門風順序中玩家前一位的上家宣告。魚牌記憶翻轉不影響計番。
- 碰、上、明槓為**開牌**（`open: true`），一旦宣告就不再計「門前清」，但自摸仍按 `context.selfDraw` 計算；暗槓（`open: false`）視作暗刻，仍可計自摸、門前清與坎坎胡。
- **天胡／地胡**：起手 13 張普通牌補花後，檢查牌尾第一張自摸；莊家成牌為天胡，其他門風為地胡，兩者皆以 13 番例牌結局，已含自摸與門前清。開局七／八花即時胡牌時同樣加上此例牌（共用的自摸只計一次）。未成牌時不消耗牌牆，不影響正常流程。
- 槓子與碰在各牌型中視為刻子，上視為順子；因此暗槓、碰仍可計入清一色、混一色與對對糊；沒有碰、明槓（暗槓可以）才計坎坎胡。
- 「對對糊」是只有刻子的牌型（3 番）；「坎坎胡」是沒有碰／明槓的對對胡（又稱四暗刻，8 番），已吸收對對糊與門前清。「花幺九」與坎坎胡可疊加，但共用的對對糊只計一次，胡牌細項會列出「重疊扣減」。
- 自訂 13 番牌型：綠一色（只有二、三、四、六、八索或發財）、藍一色（只有東、南、西、北、白板或八筒）。
- 番子刻子會在胡牌細項標明中、發、白或場風／門風；場風與門風重疊時該刻子計 2 番。番子已從「小番」清單移除，所以只有番子的小牌不會再被標成雞糊。
- 疊加改採 `ABSORBS` 表：若牌型 A 依定義必定包含 B，就只計較高番的 A，並以 `includes` 顯示「已包含」；只是有時重疊的牌型（例如坎坎胡＋大三元、十八羅漢＋坎坎胡）仍可疊加，若共用同一子牌型則以「重疊扣減」扣回重複番數。七對子、綠一色、藍一色仍保留。
- 番數上限固定為無上限；不換算分數，胡牌只累加番數。
- 十三幺、九子連環、七對子必須門前清；特殊牌型仍需合法牌型。
- 原先將七對子稱為「花糊」是誤名，現已按維基百科改為「七對子（嚦咕嚦咕）」；「花糊」專指七張花牌。
- **海底撈月**改為：倒數**剩餘 5 秒內**自摸或胡對手打出牌並胡牌即計 1 番；自摸仍按胡牌來源另計，不因海底撈月被吸收。5 秒前胡牌則不算（由 `winContext().haidi` 判斷）。此屋規與花糊等一律納入計番。
